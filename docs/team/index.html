How to see it all locally

Rebuild and serve

python3 publish.py                          # rebuilds dist/: timelines, pitch, every page, this map
cd dist && python3 -m http.server 8767      # then open http://localhost:8767/

dist/ is not committed, so building publishes nothing. python3 publish.py --site rebuilds docs/ for GitHub Pages, which is public once committed and pushed: the two spines, and this map with every page behind it.
